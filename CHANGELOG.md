# Changelog

## 1.0.1
- First fshost release, based on kus/CS2-Remove-Map-Weapons 1.0.1. Plugin name stays "Remove Map Weapons".
- Built against CounterStrikeSharp 1.0.407 (mrc4tt/CounterStrikeSharp) on .NET 10.
- When loaded mid-map with `css_plugins load`, removes the map's weapons right away instead of at the next round start.
